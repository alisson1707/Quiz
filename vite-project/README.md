📚 Quiz App - Programação para Web

Este projeto é um sistema de quiz desenvolvido com React + TypeScript, com navegação entre telas, pontuação e armazenamento de dados no navegador.

🚀 Tecnologias utilizadas
React
TypeScript
React Router DOM
LocalStorage (para salvar dados no navegador)
Vite (caso esteja usando Vite)
📁 Como instalar o projeto

Clone o repositório:

git clone https://github.com/alisson1707/Quiz

Entre na pasta do projeto:

cd vite-project

Instale as dependências:

npm install
▶️ Como rodar o projeto

Inicie o servidor de desenvolvimento:

npm run dev

Depois abra no navegador:

http://localhost:5173
📦 Como fazer build (produção)
npm run build
🧪 Funcionalidades do sistema
Tela inicial com botão de início
Quiz com perguntas e alternativas
Verificação de respostas (certo/errado)
Contagem de acertos e erros
Tela de resultado final
Salvamento de perguntas no navegador (LocalStorage)
💾 Dados salvos no navegador

As perguntas são salvas automaticamente no LocalStorage com a chave:

quizQuestions
